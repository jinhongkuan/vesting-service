# Backend Take-Home Assignment

You are already in the correct repository. There is no separate repository link.

This branch (`main`) contains only the process guide:
- `HOME_TASK_GUIDE.pdf`

## Start coding

Switch to one of these branches in this same repository:

- `scratch`: Full requirements; candidate can implement with their preferred backend stack.
- `boiler-node`: Starter Node.js + TypeScript service scaffold.
- `boiler-go`: Starter Go service scaffold.
- `boiler-rust`: Starter Rust service scaffold.
- `boiler-java`: Starter Java Spring Boot service scaffold.

If you only see `HOME_TASK_GUIDE.pdf`, you are on `main`. Use the branch switcher in GitHub or run:

```bash
git checkout scratch
# or
git checkout boiler-node
# or
git checkout boiler-go
# or
git checkout boiler-rust
# or
git checkout boiler-java
```

Then open that branch's `README.md` and follow its instructions.

## Submission note

Unless you are told otherwise, submit your completed work from this repository (or your fork), including branch name and test commands.
